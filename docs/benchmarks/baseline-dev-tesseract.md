# OCR benchmark: baseline-dev-tesseract

Generated by `python -m scripts.bench_ocr report` from the raw results of CI run [38389196068](https://github.com/pavan-dangeti/VeriTrack-AI/actions/runs/38389196068) (x86-64).

Recorded before any reader fix and before runs stored which set they read; it used the generator's default seed 7 (the development set). The definition of *verified* below describes the final reader; at this commit verification was weaker: a misread totals label could pass with nothing compared, and partial grids, unreadable employee IDs, ambiguous leave tasks and handwriting were not checked (see [the benchmark write-up](../ocr-benchmark.md)).

The `simulated_photo` group is generated from screenshots; no real photographs were tested.

**Verified** means every day's hours agree with the printed row and sheet totals, the employee ID and period were read, and every row's task was read clearly enough to tell leave from work. Project and task codes, names, roles and task titles are not cross-checked.
